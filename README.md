# Crowdfunding Website - Frontend

This repository contains the **frontend** of a Crowdfunding website built using **HTML, CSS, and JavaScript**. The website allows users to create campaigns, donate to campaigns, and provides user authentication. An **Admin Dashboard** is planned for future deployment.

---

## Features

- **User Authentication**: Login and signup functionality for users.
- **Create Campaigns**: Users can create their own crowdfunding campaigns.
- **Donate to Campaigns**: Users can contribute to existing campaigns.
- **Responsive Design**: Works on desktops, tablets, and mobile devices.
- **Admin Dashboard**: Planned feature for managing users and campaigns (not yet deployed).

---

## Frontend Tech Stack

- **HTML5**: Structuring the web pages.
- **CSS3**: Styling the website with responsive and modern design.
- **JavaScript**: Dynamic behavior, form validation, and API integration.

> **Note:** The backend API is hosted in a separate repository. Frontend communicates with the backend via RESTful API calls.

---

## Setup Instructions

1. **Clone the repository**
```
git clone https://github.com/Radhika252007/CrowdFundingFrontend
```
2. **Navigate to the Folder**
```
cd CrowdFundingFrontend
```
3. **Open index.html in your browser**
   You can directly open the HTML file, or serve it using a local server like Live Server (VS Code extension) for full functionality.
